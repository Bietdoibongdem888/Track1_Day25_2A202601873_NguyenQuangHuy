# Value metric benchmarks

Checked: **2026-08-27**.

| Product | Comparable job | Value metric | Published price | Source | Status / note |
|---|---|---|---|---|---|
| Stripe Radar | Automated transaction fraud screening and fraud alerts | Plan subscription plus evaluated transaction / pay-as-you-go | Radar Standard starts at $10/month; Radar Plus $14/month; Radar Pro $20/month for the business pricing shown | https://stripe.com/radar/pricing | Current first-party starting/list pricing. Adjacent product, not a 1:1 investigation-copilot benchmark. |
| Fingerprint Pro Plus | Browser/mobile device identification and risk signals | API request / identification | $99/month for 20K API calls; then $4 per 1,000 additional calls | https://fingerprint.com/pricing/ | Current first-party starting/list pricing. Public Enterprise price is custom. |

Stripe Radar and Fingerprint monetize fraud/risk activity primarily through usage-like units: evaluated payment activity or API identifications. They do not perform exactly the same job as P-015: P-015 provides human-reviewed investigation support with lower autonomy and weaker attribution, so direct outcome pricing would be premature. These benchmarks support a measurable usage component but do not prove P-015's price; the proposed Hybrid metric is a platform fee for workflow/integration plus 32,000 VND per completed grounded investigation package.
